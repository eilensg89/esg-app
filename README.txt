IMPORTANTE ANTES DE PRODUCCIÓN PÚBLICA
Esta V1 es un frontend estático funcional. Para uso real con clientes debe conectarse a infraestructura segura para:
- base de datos / backend;
- autenticación y enlaces privados;
- persistencia segura de firmas y acuerdos;
- envío de emails;
- verificación de pagos;
- almacenamiento de archivos;
- estados de cliente/proyecto.

Los botones de Zelle y PayPal solicitan por WhatsApp los datos vigentes para no inventar identificadores de pago no proporcionados.
