Coloca aquí las fotos autorizadas de testimonios cuando estén listas.
El archivo data/testimonials.json puede recibir objetos con esta estructura:
{
  "name": "Nombre",
  "business": "Negocio",
  "service": "Servicio contratado",
  "quote": "Testimonio",
  "image": "/assets/testimonials/foto.webp",
  "url": "https://..."
}
Mientras el archivo esté vacío, la sección no se muestra.
