# Sistema Visual ESG — Leather · Stone · Relief

Este es el lenguaje visual aprobado para la nueva experiencia ESG y puede reutilizarse como dirección para posts, carruseles, portadas y futuras interfaces.

## Idea central

La pieza debe sentirse como un objeto táctil premium, no como un diseño plano. El contenido aparece en módulos de piedra beige elevados sobre una superficie de cuero marrón, con detalles metálicos dorados. El resultado debe transmitir lujo cálido, tecnología humana y una experiencia que invita a tocar.

## Paleta base

- Cuero profundo: `#4A210F`
- Cuero oscuro: `#2D1007`
- Piedra beige: `#EFE2CA`
- Piedra clara: `#F8EDD9`
- Piedra sombreada: `#DCC7A5`
- Dorado principal: `#C58A26`
- Dorado luz: `#F2C76E`
- Dorado oscuro: `#8D5D11`
- Tinta marrón: `#402313`
- Crema: `#FFF8EB`

## Forma

- Tarjetas con esquinas muy redondeadas o curvas orgánicas.
- Los módulos deben parecer piezas físicas apoyadas sobre el fondo.
- Usar sombras dobles: sombra exterior cálida + luz interior superior.
- Bordes dorados finos, nunca gruesos o estridentes.
- Los botones principales se ven “presionables”: al tocar, bajan 1–2 px y reducen la sombra.

## Materiales

### Cuero
Se utiliza como superficie madre, marco, fondo o zona de profundidad. No debe cubrir todos los elementos; su función es dar contraste y sensación premium.

### Piedra
Se utiliza para información, botones, tarjetas, precios y módulos. Debe sentirse cálida, no gris fría.

### Dorado
Se reserva para bordes, jerarquía, símbolos, CTA, mariposa y pequeños detalles. El dorado no debe dominar toda la pieza.

## Tipografía

- Titulares: serif editorial elegante, estilo Cormorant Garamond.
- Texto funcional: sans serif limpia, estilo DM Sans.
- Titulares grandes pero con aire; nunca cortar palabras.
- No usar demasiadas mayúsculas. Reservarlas para etiquetas pequeñas/eyebrows.

## Elenia

Elenia funciona como hilo narrativo y guía de la experiencia, no como decoración. Puede aparecer para:

- abrir una pieza;
- introducir una decisión;
- celebrar una acción completada;
- explicar el siguiente paso;
- acompañar CTA;
- usar su moto en piezas de movimiento, transición o actitud.

Mensajes cortos. Ejemplos:

- “Estás a un paso de tu cambio.”
- “Elige por dónde quieres comenzar.”
- “Tu idea ya tiene dirección.”
- “Ahora empieza la transformación.”

## Composición para posts

1. Un módulo protagonista grande (imagen, avatar o mensaje central).
2. Entre 2 y 5 módulos secundarios en relieve.
3. Una acción o frase central muy clara.
4. Mariposa dorada como firma sutil.
5. Espacio negativo suficiente: evitar llenar todos los huecos.

## Interacción visual

Aunque un post no sea interactivo, debe parecer que los módulos podrían tocarse. Esa es la firma visual del sistema.

## Qué evitar

- Plantillas planas genéricas.
- Dorado excesivo.
- Fondos blancos sin materialidad.
- 3D infantil o plástico brillante.
- Exceso de texto dentro de un solo módulo.
- Iconografía de estilos mezclados.
- Sombras negras duras.
- Elementos decorativos inventados sin función.

## Fórmula resumida

**Cuero = profundidad**  
**Piedra = contenido**  
**Dorado = jerarquía**  
**Elenia = guía**  
**Relieve = firma de experiencia**
